# Color Cipher

A web-based encryption and decryption project that uses colors
to represent encrypted information.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Encryption
- Decryption
- User-friendly interface
- Color-based cipher system

## How It Works

The user enters information into the website.
The JavaScript processes the input using the Color Cipher
encryption method and produces the encrypted result.

The encrypted information can then be decrypted back
to the original information.

## How to Run

Download or clone this repository and open `index.html`
in a web browser.
